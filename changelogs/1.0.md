# Fantasy Weapons 1.0

- Added 15 weapons: Lady Maria's Blade, Ornstein's Spear, Grave Sentinel Halberd, Wind Worshipper Sword, Flesh of the Feaster Rapier, Dead Gladiator Sword, Redeemer Sword, Twinned Glaive, Evening Ghost Dagger, Ronin Katana, Old Knight Hammer, Silver Knight Sword, Ashen Judgment Battleaxe, Frostbite Axe, Dawncrest Glaive.
- Added a description tooltip for Blazing Stone.
- Expanded translations to 12 languages: English, Japanese, Ukrainian, Russian, Simplified Chinese, Turkish, Korean, Spanish, Brazilian Portuguese, German, French, and Polish.
- Expanded Forge, NeoForge, and Fabric support, including Minecraft 26.1.2, 26.2, and 26.3.
- Replaced the previous configuration library with native Forge/NeoForge configuration and Cloth Config on Fabric.

Fabric requires Fabric API and Cloth Config. Use dependency versions matching your Minecraft version. 
Configuration handling has changed, review your settings after updating.
